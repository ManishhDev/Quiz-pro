# Google Developer Club Selection Quiz App

This is a React-based quiz application built as part of the Google Developer Club selection process. The app allows users to participate in a quiz that tests their knowledge on various topics.

## ✨ Features

- **Multiple Choice Questions**: Users can answer multiple-choice questions on various topics.
- **Timer**: A countdown timer is provided to make the quiz more engaging.
- **Score Tracking**: Displays the score at the end of the quiz.
- **Responsive Design**: The app is designed to work seamlessly on both desktop and mobile devices.

## 🛠 Tech Stack

- **Frontend**: React.js
- **State Management**: React's `useState` and `useEffect`
- **Styling**: CSS
